# Project instructions

## Exploration boundaries
- Never search, read, or list files inside `node_modules`, `dist`, `.git`, or any `build` folder.
- Unless explicitly asked otherwise, only explore `backend/src`, `frontend/src`, and root-level config files (e.g. `package.json`, `.env.example`, `README.md`).

## Reporting style
- When explaining findings, describe them in your own words — don't paste back full file contents.
